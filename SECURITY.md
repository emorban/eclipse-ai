# Security

Eclipse AI is a **public, sanitized engineering portfolio**, not the live Eclipse operator environment.

## Please do not publish

Pull requests and issues must not include:

- API keys, tokens, credentials, webhook secrets, or secret locations
- personal or long-term operator memory
- private filesystem paths, hostnames, IPs, or machine identifiers
- live provider/account identifiers
- private messaging or channel configuration
- current task queues, private project state, or customer information
- operational recovery procedures, production runbooks, or private logs

## Reporting a concern

If you believe sensitive information has been published here, please do **not** open a public issue containing the sensitive value. Use the contact path associated with the repository owner or ELISON INC and provide only the minimum information needed to identify the affected file or commit.

## Scope

The code in this repository is representative portfolio material. It should not be interpreted as the full security architecture of the private Eclipse runtime.
